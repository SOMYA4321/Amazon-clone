# 🛒 Amazon Clone (HTML & CSS)

A simple **Amazon homepage clone** built using **HTML and CSS**, focusing on layout design, styling, and responsive UI.

---

## 🚀 Features

* 🏠 Amazon-like homepage layout
* 🎨 Clean and structured UI design
* 📦 Product sections & banners
* 🧭 Navigation bar with search box
* 📱 Basic responsive design

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**

---

## 📂 Project Structure

```
amazon-clone/
│── index.html
│── style.css
│── images/
```

---

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
